# GQL 兼容层方法学手册(可迁移配方)

> 定位:做「诚实兼容层」的通用配方,**不限于 GQL/Cypher 这对语言**。每条原则必须配教训
> 案例——没有案例的原则会被后人当官僚条文绕过。硬事实(是什么)在
> `docs/gql_semantic_map.md`;历史与待办在 `_HANDOVER_GQL.md` 五/六节;本手册放
> "怎么做事"。数据截至 2026-10-02(多跳 QPPI 轮收工)。

## 0. 总纲:0 静默错答

**宁响亮拒绝,不静默错答。** 新功能面开工前先问一句"会不会静默错";会,就先定响亮出口。
错答案比没有答案糟得多——兼容层的全部信誉建立在"错了会喊"上。

案例:异构列表 bind 期 cast-erase(`[1,'a',…]` 归一后 max/min 给错结果)、JSON 属性文本序
比较(`>=100` 命中 33/9/33.5)、合成名从 `RETURN *` 漏成未声明列——三个静默错类全是
线下探机/红队式自查抓的,不是用户报的。

## 1. 双跑对照设计法

每条 GQL 用例**旁挂等价 Cypher、断言同一期望**:`.test` 里 GQL 语句与手写 Cypher 各跑一遍
对同一期望值。"翻译对不对"从评审意见变成可执行命题。

- 好处:翻译器的任何回归直接挂测试;双跑本身就是语义论证的留痕。
- 反面案例:**G115 `PROPERTY_EXISTS` 矩阵虚标**——矩阵里记 ✓("parsed as-is")但从未
  执行验证,评估日一跑就死在 `function PROPERTY_EXISTS does not exist`。矩阵里的 ✓
  如果不是从测试回读的,就是传闻。修复时按 Neo4j `PropertyExistsToIsNotNull`
  (Apache-2.0)抄写补双跑用例,矩阵才转正。
- 推论:**矩阵/文档的每个 ✓ 必须能指到一个测试名**(语义地图的行格式就是为此)。

## 2. 三档码断言 + 窄贴码(错码比无码糟)

给错误贴 GQLSTATUS 码时,**错码比无码更糟**——错码让调用方按错误条件分支走错路,无码
只是不够信息。两件配套:

1. **窄贴码**:贴码面必须比语料/规范钉码面窄或恰好,宁可留无码。
2. **三档断言**:码匹配=过 / 无码=pass-with-note / **错码=挂**。它既是保险也是探针。

案例:
- **G2000 脚枪**:曾拟给所有 `unsupported()` 无差别贴 `[42000]`+三档判——但 Create2 [7]
  今天绿(拒绝被 any-error 满足),无差别贴码会**砸绿场景**。贴码面收窄到语料真钉码处
  (schema 目录错误 `[42000]`、READ ONLY 事务 `[25G03]`),其余留无码。
- **graph-types [6] 现行犯**:语料题名"重复属性名"、body 却是 [4] 的多标签 copy-paste
  (属性无一重复),钉 `42000` vs 实际拒因 `22G0P`——三档断言的 wrong-gqlstatus 档
  **当场抓到**,转 soft-code 降档+脚注披露。没有三档,这个语料矛盾会以"绿"混过去。

## 3. 咨询闭环(回帖必先独立验证)

外部 AI / 文档 / 标准文本的回帖**不是权威**,是待验假设。闭环:

> 简报(问题清单+可核事实)→ 回帖 → **独立验证再采纳**(探机复现 + 语料/源码交叉核对,
> **先纠错后采纳**)→ 修正落地序 → 实现 → 门禁 → 文档真相同步 → 本地提交。

验证轮的**修正比采纳更有价值**——四轮咨询三次修正了回帖错误:

- **Q3 简报事实 #3 自错**:简报称"语料无 GQLSTATUS 码断言",实际语料含 20 处
  (`an exception condition should be raised: <code>` 句式)——是自家 run_tck 主动丢弃。
  自己的简报也会错。
- **Q4 三层反转**:回帖文法读对(USE 无 GRAPH 关键字)但「`USE /path` 独立语句今天能跑」
  证伪;真形态是**前缀从句** `USE /foo/g MATCH …`;我方旧归因(名位不收 /path)也是错的。
  一次验证推翻两层。
- **Q5-2① 外部语义正确 ≠ 引擎映射正确**:回帖的 ISO SIMPLE 定义对、推理对,但
  「引擎 `*ACYCLIC` = ISO SIMPLE」错——引擎只保中间点互异,照抄=放出非 SIMPLE 行走=
  静默错答。四源互证管不到我方引擎侧;**引擎原语的精确语义必须本地探机**(6 行探针拦下
  一个错答类)。

## 4. 问题语料三件套(冻结 + 例外 + 脚注)

TCK 语料 **vendored 冻结不改**。判定标准:只有**语料自相矛盾或输入缺失**才算语料问题;
产品缺口不算(那是产品账)。确认语料问题后固定处置:

1. **语料冻结不动**;2. **harness 例外**(values-only / When 重释 allowlist / soft-code
降档 / fixture 补数);3. **REPORT.md 脚注披露**。

先例 4 例:Aggregation3 [1](列名自相矛盾)、Create1 [7](When 漏 IF NOT EXISTS)、
graph-types [6](题文不符 copy-paste)、catalog-1 fixture(输入缺失)。
例外必须"例外到场景"而不是"例外到断言"——把整个场景的判定口径重释,不让单条断言豁免
悄悄放行。

## 5. 归因必须过执行验证

**读代码/读语法推断会骗人,探机复现才作数。** 三次教训都是"推断自信满满、一跑就翻":

| 案例 | 旧归因(错) | 探机真相 |
|---|---|---|
| G115 虚标 | "parsed-as-is 支持" | 函数不存在,执行即死 |
| 「布尔不校验」 | "Ladybug 布尔运算不校验操作数类型" | binder 有真类型检查;实为 harness 正则 `.+` 不跨行误判多行错误 |
| USE 归因两轮皆错 | 我方:"名位不收 /path";回帖:"独立 USE 语句可跑" | USE 是前缀从句;`GRAPH` 被当图名 |

操作化:凡是要写进 README/矩阵/差异清单的断言,先做一个最小探针(6 行级别)或一条
error 用例;探机脚本用完即删,结论落测试。

## 6. 新事实必落测试(同一提交)

任何新钉的语义事实(探机结论、语义差异、红线),**同一提交里必须带测试**并回写
`docs/gql_semantic_map.md` 对应行。否则地图退化成传闻,半年后没人知道哪行还活着。
错误消息变化 = 测试期望同步改(`unsupported.test` 的 pin 就是消息级契约)。

## 7. 红线专项:合成名泄漏与拼写分裂

- **合成名泄漏 = 列集静默错的固定出口**(教训 ⑧):翻译层给匿名模式/包装谓词生成的名字
  (`_gql_nlN`/`_gql_ppN`/`_gql_veN`/`_gql_ueN`/`_gql_vnN`)都会从 `RETURN *`/`SELECT *`
  泄漏成用户没声明的结果列。切片交付的 wrap 引入此错类后探机坐实,顺藤摸出两类 P7 存量。
  **规矩:凡生成绑定名,必查星号投影**——要么星号重写为显式列集,要么响亮拒
  (当前统一拒 `star projection with generated pattern bindings`)。
- **拼写分裂**:凡"改绑定值形状"(如边绑定 RECURSIVE_REL→列表),必查**两种拼写**是否
  分裂——paren 内腔与直接槽曾一个包列表一个不包,同一 GQL 语义两种形状=静默不一致。
  规矩:形状统一以语义为准,双拼写共享同一条发射路径。

## 8. subagent 纪律(32k 生存)

任务书**钉死**三条,否则一次响应就撞 output 上限(两次击杀皆因此):

1. 单次 Write ≤ 400 行(分片小步写);2. 报告 ≤ 40 行;3. **禁止粘贴全量测试输出**
   (只报计数与首个失败)。

多个 subagent 碰同一文件(如 `gql_transformer.cpp`)必须**串行**;主会话负责集成、
验证、红线复查——subagent 交付不等于过关(多跳 QPPI 切片 A 的星号泄漏就是集成验证抓的)。

## 9. 执行闭环(每轮照此,六轮验证有效)

1. 简报(问题清单+可核事实);2. 外部回帖(若有);3. 独立验证再采纳(原则 3);
4. 修正落地序;5. 分片实现(subagent 小步写+主会话集成,原则 8);6. **门禁**:
   `_build_gql.bat` + 自测全绿 + TCK 不降(190 绿/9 挂/7 跳)+ wrong-GQLSTATUS=0 +
   引擎侧改动额外跑全量引擎回归(`E2E_TEST_FILES_DIRECTORY=test … --gtest_filter="*"`,
   离线基线=1972/1975,3 例 INSTALL 需外网必挂);7. 文档真相同步(README / 语义地图 /
   `_HANDOVER_GQL.md` / REPORT 脚注 / memory 只留指针);8. **git 本地提交,绝不 push**。
